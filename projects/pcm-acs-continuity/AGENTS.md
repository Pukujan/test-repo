# PCM–ACS Continuity Project

This project studies resumability and bounded work across sessions. Follow the root lab contract.

Every live GitHub issue controls its own scope, decisions and corrections. An older checkpoint is an as-of projection, not permission to repeat its next action. Read the live issue before material work. If the plan and current issue conflict, reconcile before creating deliverables.

Use only the named experiment workspace; never edit other experiments or the production ACS website. Do not modify recorded checkpoints, accepted decisions or a precondition merely to get a green status. A 'CURRENT' revision only establishes freshness, not approval.

This project may exercise a pre-release PCM/ACS adapter. A missing/unverifiable preflight is not evidence of valid state. Write an observable outcome report and cite the issue URL and the files actually touched.
